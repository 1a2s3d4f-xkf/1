# 安全边界和扩展约定

## 威胁模型

防护对象：模型误调用、错误参数、路径越界、文件中的提示注入，以及无意覆盖资料。
信任对象：安装的软件、项目代码、人工选择的配置、同一账户下的其他进程，以及本机 Ollama 服务。
**本项目不是抵御恶意本地进程的 OS 沙箱**。请使用普通用户权限，在专用目录放入无敏感信息的实验样例。

## 当前强制执行的限制

1. API 仅允许 HTTP 数字回环地址 127.0.0.1 或 ::1 和明确端口，不接受域名、远程 URL、凭证、路径/查询参数。
   HTTP 客户端不使用环境代理，不跟随重定向，不自动重试。请求前检查远程模型标记，推荐服务端关闭云功能。
2. 工具由固定注册表分派；参数必须匹配字段/类型。没有 shell、任意 Python、网络下载、读取环境变量、桌面控制工具。
3. 模型文件根目录固定为配置文件旁的 `workspace/`。禁止绝对路径、`..`、反斜杠、冒号（含 NTFS ADS）、隐藏文件、
   Windows 设备保留名称和非常规路径字符。文件名仅用英文/数字/点/下划线/连字符；文本内容支持中文。
4. lstat 检查路径链，拒绝符号链接、Windows reparse point/junction、硬链接、设备和 FIFO；读取后检查打开文件的 inode/type。
   POSIX 可用时使用 O_NOFOLLOW/O_NONBLOCK。目录 listing 不跟随链接。
5. 文件操作只允许 .txt/.md/.json/.csv，读取和创建默认上限 8192 字节。写入仅新建且父目录必须已存在。
   使用 O_EXCL 防覆盖；批准后重新验证路径。没有模型可调用的删除/覆盖/重命名工具。
6. 默认仅预览；实际创建需要 `--apply` + TTY 中输入精确确认字符串。非交互输入、回车和拒绝都会停止写入任务。
   预览/模型输出中的控制字符和双向控制符被转义，减少终端显示欺骗。
7. 任务默认最多 6 轮模型请求、12 次工具调用、32KiB 会话内容；响应最多 2MiB。
   未完整结束、生成截断、格式畸形或超过工具预算的批次不会执行。数值计算限制 AST、长度和中间值。
8. 执行前写审计记录，执行后记录结果状态；日志不可写则停止。参数只存 SHA-256，不存原文。
   发生未知工具调用时，日志使用 unknown_tool，避免模型通过工具名写入任意内容。

## 不能保证的事项

- 多个本地进程恶意地在路径检查与 open 之间交换父目录，仍可能造成 TOCTOU 竞争；此跨平台实现没有完整的
  Linux dir_fd 链或 Windows 句柄级相对打开。不要把它宣称为强沙箱；生产级扩展需容器/独立账户/平台专用隔离。
- Windows junction 检查在代码和模拟属性测试中覆盖；是否能在你的真实文件系统准确拦截需本机验收。
  测试允许因 OS 权限而跳过 symlink/FIFO 特定用例，不能把跳过称为通过。
- 多步骤任务不是数据库事务。停止、Ctrl+C、磁盘满或审计完成记录失败时，之前的文件可能已经存在，
  新文件可能不完整。不会自动回滚或自动重试写操作。人工查看工作区后再运行。
- 提示注入可能改变模型行为、文本和选用工具，但不能授予注册表之外的能力。不要只依赖 SYSTEM 提示词保障安全。
- 文件扩展名白名单不等于内容无害；Markdown 可包含链接或主动内容。用纯文本编辑器查看产物，不执行其内容。
- 哈希不是加密，低熵参数可被猜测；审计日志不是防篡改存证。它仍应作为本地敏感元数据保管。
- 上下文字节预算不等于精确 token 预算，服务端仍可能截断长输入。接近 num_ctx 时停止，复杂任务应拆分。
- 模型最终回答可能有误，应依据工具返回状态和实际文件核实。smoke 通过只证明那一次工具往返，不证明所有任务可靠。

## 后续添加工具

优先增加只读能力（例如专门窗口的截图），为每个写入/点击/发送动作定义参数白名单、明确授权、频率上限和审计。
通过可重复的离线测试后，再进行本机真实验收。发送消息、登录、支付、删除文件等不属于本原型能力。
不要为了快速实现“自动操作电脑”而直接添加 unrestricted exec 或把根目录改成用户主目录。
